# Nieuwe website — concept

Deze map is een afzonderlijke conceptversie van Rattenvanger van Haarlem. De bestaande website in de repository-root is niet aangepast.

- Preview: `/concept/` (zodra GitHub Pages de nieuwe bestanden heeft gepubliceerd).
- Alle pagina's bevatten voorlopig `noindex,nofollow` en een concept-robots.txt om indexering vóór goedkeuring te voorkomen.
- De bestaande logo-afbeelding wordt hergebruikt via `../IMG_0106.PNG`.
- De rattenkaart en bewonersregistratie gebruiken dezelfde bestaande Apps Script-webapp en categorieën.
- De officiële meldroute blijft een rechtstreekse e-mail aan Spaarnelanden.
- De inhoud maakt duidelijk onderscheid tussen officiële meldingen en vrijwillige bewonerswaarnemingen.

Voor livegang moeten onder meer de actuele contact- en opvolgafspraken bij Spaarnelanden worden gecontroleerd, de privacy-/technische verwerking worden nagekeken, de noindex-regels worden verwijderd en een sitemap/robots.txt voor de definitieve URL's worden geplaatst.
